# Bible Version Comparisons

Show verses side by side to see the differences between old and new versions.

# 200 Omissions

The idea came from a pamphlet called the New Eye Opener which shows a list of almost 200 verses which have been removed or changed from modern Bible versions.  The idea is to go down the list and look up each verse to see them all at once.

Now with a programming skills, and the help of AI, it is easier to compile verses from different versions.  The initial commit shows a simple html page with the verses in question.
